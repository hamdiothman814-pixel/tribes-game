# 3D model credits — tribes game

The GLB models in `assets/models/` are free game assets by their original
authors. They are used inside this game only, not resold or redistributed
standalone.

- **Quaternius** (https://quaternius.com/license.html — QAL v1.0: free for
  personal, educational and commercial games, no credit required):
  Knight, Golden Knight, Soldier (male/female), Blue Soldier, Casual,
  Modular Women Soldier, Zombie, Cyberpunk Character, Toon Soldier,
  Fantasy Temple, Pirate Ship Large.
- **Kenney** (https://kenney.nl — CC0, public domain):
  hexagon kit tiles (water, grass, grass-forest, stone-mountain, path,
  village building, castle, walls, bridge), mini-forest trees and rocks,
  mini-dungeon column and chest, city-kit roads, nature-kit trees and
  canoe, and the mini character set (arena soldier, dungeon human, orc,
  forest archer, skeleton, vampire, ghost).
- **KayKit** (via the free listing that also hosts the Quaternius set;
  CC0): KayKit Knight.
- **Polygonal Mind** (via the same free listing; CC0): Robot, Zombie 44.
- **isalousberg** (via the same free listing; CC0): Homely House.

Models are loaded lazily: a model file is only downloaded the first time
its unit or terrain type appears in a game, never all upfront.
